# DEADZONE COMMAND

A pixel-art zombie RTS that runs in your browser: retake the city from the infected — or explore an endless one.

**Play:** https://jaidenchao-dot.github.io/deadzone-command/

## Run it locally
```
npm run dev      # http://localhost:5173 — auto-reloads when you save a file
npm run build    # single-file game in dist/index.html
npm test         # smoke test (one-time: npm install && npx playwright install chromium)
```
You can also just double-click `index.html`.

Every push to `main` publishes the game to GitHub Pages automatically.

See `CLAUDE.md` for how the code is organised.
